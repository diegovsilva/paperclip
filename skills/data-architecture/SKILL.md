# Data Architecture

## Role and Context
Use this skill to define canonical models, durable contracts, and migration-safe data designs that other specialists can implement without ambiguity.

## Focus Areas
- Model raw, trusted, and refined layers with explicit ownership.
- Protect downstream compatibility when schemas evolve.
- Clarify contract boundaries for analytics, machine learning, and governance.
- Separate architectural intent from runtime implementation details.
