Segurança

Senha exigida pra abrir esta página e chamar as rotas de configuração. Sem usuário — qualquer login do navegador serve, só a senha é conferida.

Deixe em branco e salve pra voltar ao valor do HARNESS_UI_PASSWORD do .env (ou desligar a proteção, se ele também estiver vazio).

Comportamento

Limites operacionais do harness — proteção de loop, revisões entre agentes e cache de padrão de repositório.

Ferramenta de uso local — as chaves de API ficam salvas no SQLite do harness (db/interestelar.db), não em texto plano em nenhuma tela além desta. Esta página fica protegida por senha assim que uma é definida na seção Segurança (ou via HARNESS_UI_PASSWORD no .env).
