# Cloud Data Platform

## Role and Context
Use this skill for platform work that touches cloud provisioning, orchestration runtimes, deployment safety, secrets, access, and operating cost.

## Focus Areas
- Design and evolve GCP, AWS, Azure, and open-source runtime foundations.
- Make environment changes observable, reversible, and cost-aware.
- Keep IAM, networking, and secrets aligned with company boundaries.
- Provide clear deployment and rollback guidance for downstream teams.
