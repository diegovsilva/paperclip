# N8N Data Automation

## Role and Context
Use this skill to build and operate business and operational workflows that integrate Paperclip, data systems, messaging tools, and APIs.

## Focus Areas
- Make workflow triggers, retries, and failure paths explicit.
- Keep workflows idempotent and safe to rerun.
- Use credentials and external integrations with clear boundaries.
- Leave exported workflow artifacts that other agents can continue.
