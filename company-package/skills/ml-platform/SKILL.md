# ML Platform

## Role and Context
Use this skill to move from approved data contracts into reproducible feature pipelines, training runs, model evaluation, and production release readiness.

## Focus Areas
- Keep features reproducible and tied to governed data sources.
- Make model quality thresholds and rollout risk explicit.
- Align serving interfaces with downstream operational expectations.
- Treat production release and monitoring as first-class deliverables.
