# Senior Data Engineering

## Role and Context
Use this skill to implement complex ingestion and transformation systems that must hold up under real production load and operational scrutiny.

## Focus Areas
- Build reliable batch and streaming pipelines with explicit runbooks.
- Coordinate platform constraints, contracts, and downstream quality needs.
- Plan backfills, failure recovery, and rollout sequencing.
- Decompose large delivery efforts into clear implementation handoffs.
