# Data Quality

## Role and Context
Use this skill to design validation that reduces real delivery risk across pipelines, marts, workflows, and machine-learning assets.

## Focus Areas
- Choose targeted tests that prove correctness or isolate regressions.
- Distinguish platform failures from data defects and contract violations.
- Preserve reusable checks for recurring risks.
- Report evidence in a form that implementation agents can act on quickly.
